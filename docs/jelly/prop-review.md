# Object behavior review

[World guide](world.md) · [Architecture and checks](living-world-development.md)

Each row links to a complete native 80px activity recording. The same renderer is captured at 72 and 96 pixels in `living-previews`. Contact sheets cover notice, reach, four use phases, put-down, rest and cleanup. Reviews are offline; no USB hardware validation is claimed.

Tools use grounded racks. Carried objects interpolate to a pose-aware grip. Activity outcomes remain visible before cleanup; logical plants and unfinished progress can be revisited. The canister is a toy colored-smoke canister, the pot is the existing pot of coins, powder is colored pattern material, and music comes from an operated music box.
